# STIY
Lightweight dark browser-style web app for Chromebook and mobile.

## Deploy
Keep all files in the repository root, including `assets/`. In GitHub Settings → Pages choose **Deploy from a branch**, `main`, `/(root)`, then Save.

## Included
- Multi-tabs, address bar, navigation, bookmarks
- STIY-branded search interface using Brave Search (not Google)
- Website view with external-open fallback when a site blocks iframes
- STIY AI interface placeholder
- Responsive Chromebook/mobile layout

## Limitations
GitHub Pages is static hosting, not a full Chromium browser. Search results currently open on Brave; inline results need a search API and secure backend. Live AI needs a secure backend and provider credentials. Roblox generally needs its supported client and is not guaranteed to run in a webpage. No website can promise zero lag or guaranteed 60 FPS. STIY does not disguise itself or evade school-managed restrictions.
